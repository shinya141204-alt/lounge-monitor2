## 4. note 投稿・有料ライン設定時の実務チェックリスト

1. **見出し画像の添付**：`相席ナビ` のクリーンミニマルトーン（ニュートラルブラック基調）に合わせた16:9アイキャッチを設定すると、タイムライン上での信頼感が統一されます。
2. **有料記事（`05`・`06`）の価格と設定**：
   - 販売価格：**300円**（note 最低価格帯かつ「単独待機10分＝220〜330円」との比較アンカリングが最も効く価格）
   - 返金機能：**ON（返金可）推奨**（購入ハードルが下がり、初期CVR計測に有利です）
   - SNSプロモーション機能（Xリポスト割引）：公開初週は定価300円で純粋な「無料閲覧→有料購入CVR」を計測し、2週目以降に「Xリポストで200円」を試すと拡散力との比較検証ができます。
3. **固定記事と回遊導線**：
   - 第1弾の `01_last_train_human_drama.md` をプロフィール固定記事に設定し、第4弾・第6弾の公開後にその末尾へ有料テスト記事へのnote内リンクを1行追記すると自然な回遊購入が生まれます。
