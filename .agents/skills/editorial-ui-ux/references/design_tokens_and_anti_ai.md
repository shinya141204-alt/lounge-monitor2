# 相席ナビ 脱AIデザイン ＆ クリーン・ミニマルUX 基準書

AIが生成した画面特有の「テンプレ感・安っぽさ・情報過多」を排除し、Uber・Airbnb・Linearのような「人間のプロダクトデザイナーが設計した余白・コントラスト・操作レスポンス」を維持するための詳細リファレンスです。

---

## 1. 絶対禁止する「AIっぽさ（AI Slop）」7大パターン

1. **装飾絵文字の乱用禁止**
   - ナビゲーション、ボタン、見出し、テーブルヘッダに `✨` `🔥` `💡` `🚀` `🎯` などの絵文字を飾りとして付けない。
   - 状態を示す必要がある場合は、CSSの小さなステータスドット（6〜8px丸）または簡潔な日本語ラベル（「営業中」「待ち0圏」など）で表現する。
2. **「箱の中に箱（カード過剰入れ子）」の禁止**
   - セクション枠の中にカードを作り、その中にさらに背景色付きボックスを入れる3重構造を作らない。
   - グルーピングは「余白の広狭（グループ内8px・グループ間24〜32px）」と「1pxの繊細な罫線（ヘアライン区切り）」を第一選択にする。
3. **均一な3列カード・ピルバッジ乱立の禁止**
   - すべての情報を同じサイズの角丸カードやカプセル型バッジ（pill）で並べない。
   - 1つの店舗カード・情報ブロック内で背景色付きバッジは**最大2個まで**とし、それ以外の属性（エリア名・ブランド名・補足）は枠線なしの端正なテキスト（サブカラー）で組む。
4. **「見出しを言い換えただけの説明文」の禁止**
   - 見出しの直下に、同じ意味を長く言い換えただけのリード文やAI調の煽り文（「〜を徹底解説します！」「魅力的な〜」等）を置かない。操作画面では結論と数値だけを最短距離で提示する。
5. **ネオン・派手グラデーションの新規使用禁止**
   - `#ec4899`（派手ピンク）× `#3b82f6`（派手ブルー）× `#8b5cf6`（派手パープル）のグラデーションは新規追加しない。
6. **桁ズレする数字表示の禁止**
   - 来店人数、女性比率（`%`）、待ち時間、料金、時刻を表示する要素には必ず `font-variant-numeric: tabular-nums;` を指定し、上下の行で数字の縦ラインを揃える。
7. **PC縦スクロールを壊すルート要素 `overflow` 指定の禁止**
   - `static/calm.css` 等の `html` セレクタに `overflow-x: clip` や `overflow-x: hidden` を指定しない（Chromium系PCブラウザでマウスホイール縦スクロール不能になるため）。横はみ出し制御が必要な場合は内側コンテナで行う。

## 2. カラートークン ＆ タイポグラフィ規律（Dark / Light 両対応必須）

すべてのUI追加・改修は、**ダークモード（`body:not(.theme-light)`）とライトモード（`body.theme-light`）の両方**で WCAG コントラスト比 **4.5:1 以上**（主要テキストは **5.5:1 以上**）を満たすこと。

| 役割 | ダークモード（ニュートラル黒：既定） | ライトモード（昼・クリーンライト） | 用途 |
| :--- | :--- | :--- | :--- |
| 背景ベース | `#111113` (`--calm-bg`) | `#f6f6f7` (`--calm-light-bg`) | ページ全体背景 |
| サーフェス（面） | `#1a1a1e` / `#232329` | `#ffffff` / `#ededf0` | フローティングカード・追従パネル・ボトムシート面 |
| メイン文字 | `#f4f4f5` | `#18181b` | 店名・見出し・主要数値 |
| サブ文字 | `#b4b4be` | `#52525b` | 補足・時刻・注釈（※WCAG 5.5:1以上必須） |
| アクセント（ピルCTA） | `#f4f4f5`（純白ソリッド＋`#111113`文字） | `#18181b`（純黒ソリッド＋`#ffffff`文字） | 選択中タブ・主要CTAボタン |
| 女性数値・女子モード | `#f4a8b8` | `#be123c`（ディープクリムゾン） | 女性人数・`/for-women` 強調 |
| 男性数値 | `#93c5fd` | `#1d4ed8`（ロイヤルブルー） | 男性人数 |

- **フォント ＆ レスポンシブ設計**：
  - 全画面モダン・サンセリフ統一：`Outfit`, `-apple-system`, `Hiragino Sans`, `Noto Sans JP`（明朝体や二重ブロンズ罫線は使わない）
  - **PC（1024px以上）案A・2ペイン構造**：左ペイン2列カードグリッド（`#ranking-list`）＋ 右ペイン追従詳細パネル（`#pc-store-inspector`）。PCでのカードクリック時はモーダル暗転させず右パネルを即時更新する。
  - **スマホ（768px以下）ハーフ・ボトムシート**：カードタップ時は画面下から立ち上がるボトムシート（`#analysis-modal`, 上角丸 `24px` ＋ ドラッグハンドル）で片手操作を完結させる。
  - **CSS `transition` 注意事項**：`.ranking-item` 等の `transition` プロパティには絶対に `!important` を付けないこと（自動コントラスト監査時の `transition: none !important` 注入を妨げないため）。

## 3. 機能性（Functional UX）チェック基準

1. **3秒意思決定の視線誘導**
   - 画面を開いた瞬間に「①いま一番入るべき店舗」「②女性：男性の人数と比率」「③推定待ち時間／60分後予測」がスクロールなしで目に入ること。
2. **スマホ片手（幅390px）の操作性**
   - タップ可能なボタン・タブ・リンクは高さ `38px〜44px` 以上、隣接ボタンとの間隔 `6px` 以上を確保する。
   - スマホ幅で2〜3文字だけが次行に孤立改行（文字落ち）しないよう、文字数・`padding`・`white-space: nowrap`（または適切な折り返し）を実画面幅390pxで検証する。
   - PC幅（860px / 1280px）では横スクロールバーに頼らずグローバルナビや比較表が一目で把握できること。
3. **状態の正直なフィードバック**
   - ローディング中・営業時間外・少人数（合計6名未満での予測保留）・データ0件の各状態で、空白や壊れた表示にせず「なぜその表示なのか・次にどう動けばよいか」を1行で案内する。
4. **ブランド表記・広告分離の厳守**
   - 公開UIでは単体の『オリエンタル』や内部略称『OLG』『オリラジ』を出さず、必ず正式名称 **『オリエンタルラウンジ』** に統一する。
   - 個別データコラム（`/guide/*`）の本文中に生のアフィリエイトバナーをベタ貼りせず、編集記事としての信頼性を守る（`/grooming`・`/for-women`・おすすめモーダルへ自然に送客する2ステップ導線）。
